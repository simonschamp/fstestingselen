This is a full-stack application used for demonstrating testing. 

The core components of this project are detailed below.

GitHub: https://github.com/simonschamp/fstesting


Frontend:

React

TypeScript

JavaScript

CSS



Backend:

RESTful API

NodeJs

Express

TypeScript

Database:

MongoDB


Testing: 

Cypress, Robot Framework and Selenium

Command line

npm run dev

Features/functionalities: 
Create, read, update, delete (CRUD) messages, drag-and-drop, authentication, API fetching and rendering, translations, Database mocking, form input, and submissions
